# Champion Predictor AI

## Environment

- **Never run `python3` directly on this machine.** It resolves to the
  Windows Store's App Execution Alias stub and fails with exit code 49
  ("Python was not found; run without arguments to install from the
  Microsoft Store..."). Use `.venv/Scripts/python.exe` (the project's venv,
  used by every scripted step in `champion-predictor/SKILL.md`) or the
  `python` launcher for any ad hoc verification/inspection command.
